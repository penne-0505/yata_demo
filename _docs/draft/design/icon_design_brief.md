# YATA アプリアイコン デザインブリーフ

## 1. アプリケーション概要

### 1.1 基本情報

| 項目 | 内容 |
|------|------|
| **アプリ名** | YATA |
| **正式名称** | YATA - Inventory and Order Management |
| **名称の由来** | 「屋台（やたい）」の略。小規模飲食・屋台オペレーション向けの業務管理ツール |
| **カテゴリ** | B2B / 業務効率化（POS・在庫管理・売上分析） |
| **対象プラットフォーム** | Linux, Windows, Web（Flutter製デスクトップアプリ） |
| **対象ユーザー** | 小規模飲食店・屋台・フードスタンドのオペレーター・オーナー |

### 1.2 提供価値

YATA は、小規模な飲食・屋台オペレーション向けに、以下をワンストップで管理できるアプリケーションです：

- **注文管理（POS）**: メニューからの注文作成、注文履歴、注文状況のリアルタイム確認
- **在庫管理**: 材料の入庫・出庫・廃棄ログ、在庫トランザクションの追跡
- **メニュー管理**: カテゴリ・メニュー・レシピの構成管理
- **売上分析**: 日次売上サマリー、人気メニュー分析、ピーク時間帯の可視化
- **データエクスポート**: CSV形式での売上・仕入・在庫・廃棄データの出力

### 1.3 ターゲットユーザー像

- **年齢層**: 20代〜60代
- **業態**: 屋台、ラーメン店、カフェ、フードスタンド、小規模レストラン
- **技術的親和性**: 日常でスマホ・PCを使うが、業務システムには馴染みが薄い層も含む
- **利用シーン**: 厨房での注文受付、閉店後の在庫確認・売上確認、仕入れ計画時のデータ参照
- **求めるもの**: シンプルさ、信頼感、素早い操作、見やすい数字

## 2. ブランドコンセプト

### 2.1 ブランドパーソナリティ

| 軸 | ポジション |
|----|-----------|
| **親しみやすさ ↔ プロフェッショナル** | 中央寄り〜ややプロフェッショナル |
| **伝統的 ↔ モダン** | モダン寄り |
| **遊び心 ↔ 真面目** | やや真面目 |
| **温かみ ↔ クール** | ややクール |

### 2.2 ブランドキーワード

```
信頼感（Trustworthy）    シンプル（Simple）
スピーディ（Speedy）      整理整頓（Organized）
現場の味（On-the-ground） データ駆動（Data-driven）
```

### 2.3 ブランドストーリー

> 「屋台の大将が、閉店後にスマホで今日の売上を確認する。在庫が少なくなっている材料に気づき、明日の仕入れリストをメモする。YATA は、その日常をもっとスムーズにする。」

YATA は、大規模チェーン向けの重厚なシステムではなく、**現場のオペレーターが毎日使う、軽やかで頼れる相棒**です。

名前の「屋台」という言葉には、**小さな店舗でもプロ級の運営ができる**という想いが込められています。

## 3. UIスタイル・デザイン言語

### 3.1 全体デザイン方針

- **Design System**: Material 3（Google Flutter標準）をベースにしたカスタムテーマ
- **イメージ**: 清潔感のある業務ダッシュボード。無駄を削ぎ落とした、情報が整理された画面。
- **優先事項**: 可読性 > 装飾性。データ（数字・ステータス）が一目で把握できること。

### 3.2 画面構成の特徴

| 要素 | 特徴 |
|------|------|
| **レイアウト** | カードベースのダッシュボード型。複数の指標カードをグリッド配置 |
| **ナビゲーション** | 画面上部のタブバー（注文 / 注文状況 / 履歴 / 在庫管理 / メニュー管理 / 売上分析） |
| **カード** | 白背景、角丸16px、薄いボーダー（#E2E8F0）、微細なシャドウ |
| **ボタン** | 角丸12pxのFilled Button（プライマリカラー）、アウトラインボタンと併用 |
| **フォーム** | 角丸12pxの入力フィールド、塗りつぶし背景、フォーカス時にプライマリカラーのボーダー |

### 3.3 視覚的要素の詳細

#### 角丸（Radius）
- 標準カード: 16px (`large`)
- ボタン・入力フィールド: 12px (`medium`)
- 小バッジ: 8px (`small`) / ピル型: 999px (`pill`)

#### 余白（Spacing）
- ページ全体の余白: 24px
- カード内パディング: 20px
- コンポーネント間の基本余白: 16px
- 情報密度: 中〜やや高密度（業務画面なので無駄な余白は少ない）

#### シャドウ（Elevation）
- カード: 微細なシャドウ（`level1`）— 浮き上がりを感じさせるが主張しない
- ボタン: `level2`
- ダイアログ: `level4`
- シャドウカラー: 薄いブルーグレー（`#1411182A`、透明度8%）

### 4.1 ブランドカラー（必須）

| 役割 | カラー名 | HEX | 用途 |
|------|---------|-----|------|
| **プライマリ** | ブライトブルー | `#2563EB` | メインボタン、アクティブ状態、ナビゲーションの選択状態、アイコンのメインカラー |
| **プライマリホバー** | ディープブルー | `#1D4ED8` | ホバー時、フォーカス時 |
| **プライマリソフト** | ペールブルー | `#E8EDFF` | 選択行の背景、ハイライト、バッジ背景 |

### 4.2 セマンティックカラー

| 役割 | HEX | 用途 |
|------|-----|------|
| **成功（Success）** | `#16A34A` | 在庫充足、完了ステータス、売上向上トレンド |
| **警告（Warning）** | `#F59E0B` | 在庫少、注意が必要なステータス |
| **エラー（Danger）** | `#DC2626` | 在庫切れ、エラー、キャンセル |
| **情報（Info）** | `#0284C7` | 補足情報、分析画面のアクセント |

### 4.3 ニュートラルカラー

| 役割 | HEX |
|------|-----|
| 背景 | `#F8FAFC` |
| カード表面 | `#FFFFFF` |
| ボーダー | `#E2E8F0` |
| セカンダリテキスト | `#475569` |
| プライマリテキスト | `#0F172A` |

### 4.4 カラーパレットのイメージ

```
全体像: クリアなブルーが主役の、清潔で整理されたパレット
感情: 冷静、信頼、効率性、プロフェッショナル
 avoiding: 暖色系の主張（オレンジ・赤・黄はステータス専用）、
          彩度の高いポップな色、グラデーションの多用
```

**現在の仮アイコン**: 認証画面では `Icons.storefront` に `Colors.deepOrange` を使用しているが、これは仮のプレースホルダーであり、オレンジはブランドカラーではない。

## 5. タイポグラフィ

### 5.1 フォント

- **基本フォント**: Noto Sans JP（Google Fonts）
- **ウェイト**: Regular(500) / SemiBold(600) / Bold(700)
- **特徴**: 日本語グリフの読みやすさを重視。業務画面での数字・単位表記に最適化。

### 5.2 文字スタイルの傾向

| 用途 | サイズ | ウェイト | 特徴 |
|------|--------|---------|------|
| 画面タイトル | 24px | Bold(700) | ややコンパクトな行間（1.25） |
| カードタイトル | 18px | SemiBold(600) | 情報の区切りとして使用 |
| 指標の大数字 | 24px | Bold(700) | 売上金額・在庫数などの強調表示 |
| 本文 | 14px | Medium(500) | 標準の情報テキスト |
| ラベル | 12-14px | SemiBold(600) | ボタン、バッジ、フォームラベル |

### 5.3 タイポグラフィから読み取るアイコンの方向性

- **幾何学的で整った形状**: Noto Sans JP の幾何学的なゴシック体に合う、直線的・円形的なバランスの良いアイコン
- **太さの一貫性**: フォントのMedium〜SemiBoldに相当する、中程度の線太さ（2px程度のストローク）
- **日本語コンテキスト**: 日本語UIでの違和感のない、国際的でシンプルな形状

## 6. アイコンコンセプト

### 6.1 基本コンセプト

**「小さな店舗の、頼れる業務ハブ」**

アイコンは以下の2つの要素を統合することを目指す：

1. **飲食・屋台の象徴**: 店舗、厨房、または食の要素
2. **管理・整理の象徴**: データ、リスト、ダッシュボード、または歯車/ツールの要素

### 6.2 推奨デザインディレクション

#### 方向性A: 「店舗 + 管理」の融合マーク

```
概念: 屋台/店舗のシルエットの中に、または隣に管理ツールの要素を配置
例:
- 屋根の付いた小さな店舗アイコンに、チェックリストやグラフの要素を組み合わせる
- 丸いフォルダ/ドキュメントにフォークとナイフのシンボルを組み合わせる
- レジ/カウンターの形状を抽象化したアイコン
```

#### 方向性B: 「YATA」の頭文字ベース

```
概念: 「Y」の文字を、飲食・管理の要素と組み合わせたロゴタイプ的マーク
例:
- 「Y」の縦棒をフォークに見立てる
- 「Y」の形状を屋台の屋根に見立てる
- 「Y」を円や角丸のコンテナに入れ、バッジ感を出す
```

#### 方向性C: シンプルなピクトグラム

```
概念: 単一の強い象徴（Material Design Icons の storefront, local_dining,
      inventory_2, point_of_sale などの親和性を持つ形状）
例:
- 角丸の正方形ベースに、屋台の軒先のような折り返しを付ける
- レシート/領収書の形状を抽象化（注文管理の象徴）
- 皿の上に上向き矢印（売上・成長）＋ 小さなリスト要素
```

### 6.3 形状の推奨仕様

| 要素 | 推奨 |
|------|------|
| **ベース形状** | 角丸正方形（`squircle`、半径は辺の長さの約20-25%） |
| **スタイル** | フラットデザイン（Material 3 準拠） |
| **ディテール** | 最小限。遠くからでも識別できるシンプルさ |
| **奥行き** | 2Dフラット。擬似3D、重厚なシャドウ、複雑なグラデーションは避ける |
| **線と面** | 面ベース（filled）が望ましい。細い線画（outline only）は避ける |

### 6.4 カラー仕様

```
メインアイコン:
  背景: #2563EB（プライマリブルー）
  前景: #FFFFFF（白）

ダークテーマ対応（オプション）:
  背景: #1E3A8A（ダークブルー）
  前景: #E8EDFF（ペールブルー）

モノクロ版（必要に応じて）:
  黒ベース or 白ベースでコントラストを維持
```

## 7. ムード・トーン

### 7.1 求める印象

| 感情 | 表現方法 |
|------|---------|
| **信頼感** | 安定した構図、左右対称またはバランスの取れた配置、落ち着いたブルー |
| **シンプルさ** | 要素の最小化、余白の確保、無駄な装飾の排除 |
| **スピード感** | 鋭すぎないが、軽やかな形状。重厚な枠やシャドウは避ける |
| **親しみやすさ** | 極端な尖りを避け、角丸を効果的に使用。人間味のある imperfection は許容 |
| **プロフェッショナル** | 適切なグリッド上に配置、整った幾何学的形状 |

### 7.2 避けるべき印象

```
❌ 大企業向けERPのような重厚さ・堅苦しさ
❌ ゲームやSNSのような遊び心の強さ・ポップさ
❌ 高級レストランのような贅沢さ・繊細すぎる装飾
❌ フードデリバリーアプリのような「消費者向け」のノリ
❌ コミュニケーションアプリのような「人と人を繋ぐ」印象
```

## 8. 技術仕様・要件

### 8.1 出力形式

| 用途 | 形式 | サイズ |
|------|------|--------|
| **Flutterアプリアイコン** | PNG（透明背景なし、正方形） | 1024×1024 px（ソース） |
| **Windows** | .ico（マルチサイズ） | 16, 32, 48, 256 px |
| **Linux（AppImage）** | .png | 128, 256, 512 px |
| **Web（Favicon）** | .png, .svg（オプション） | 32, 180, 192, 512 px |

### 8.2 `icons_launcher` 設定

現在の `pubspec.yaml` 設定：

```yaml
icons_launcher:
  image_path: "assets/icon/icon.png"
  platforms:
    windows:
      enable: true
    linux:
      enable: true
```

生成されるアイコンは上記のパスをソースとして、各プラットフォーム用に自動生成される。

### 8.3 安全マージン

- **重要な要素**は、画像の中央の **60% × 60%** の領域に収めること
- OSによるマスク（角丸化・円形化）が適用される可能性を考慮
- 特にAndroid/iOSでの円形アイコン表示時に端が切れないよう注意

## 10. 参考・競合アイコン分析

### 10.1 近い業態・機能の競合

| アプリ/サービス | アイコン特徴 | 差別化ポイント |
|----------------|-------------|--------------|
| **Square POS** | 白い四角に黒い「S」| シンプルすぎる。飲食の要素がない |
| **Toast POS** | トーストのイラスト | 飲食要素は強いが、カジュアルすぎる |
| **Airレジ** | 赤い「Air」のロゴ | 日本語圏POS。ブランド色が強い |
| **在庫管理アプリ（一般）** | 箱や棚のピクトグラム | 飲食の要素がない |
| **Uber Eats レストランダッシュ** | 緑の「D」| デリバリー特化。管理感がない |

### 10.2 参考にしたいアイコン（業界を問わず）

```
✅ Material Design Icons の「storefront」「receipt_long」「inventory_2」「point_of_sale」
   → シンプルさ、業務感、日本語UIとの親和性

✅ Notion / Figma / Linear
   → 幾何学的な抽象化、プロフェッショナルで親しみやすいバランス

✅ Stripe
   → 信頼感とシンプルさの両立。色の使い方が洗練されている
```

## 11. デザイン上の禁止事項（Don'ts）

```
❌ 写実的な写真やイラスト（リアルな屋台の写真、食べ物の写真等）
❌ 複雑な細部（遠くから見た時に潰れる要素）
❌ テキストロゴのみ（「YATA」の文字だけのアイコンは避ける。マーク＋文字の組み合わせは可）
❌ グラデーションの多用（特にメタリック、ガラス、ネオンのような派手な表現）
❌ 3Dレンダリング風の奥行き・影
❌ 特定の文化的ステレオタイプに依存した表現（日本の屋台＝提灯、のれん、などのみに頼る）
❌ 著作権や商標を侵害する可能性のある要素
```

## 12. デザイナーへの補足情報

### 12.1 Flutter / Material 3 との親和性

このアプリは **Flutter** フレームワークで構築され、**Material 3** のデザインシステムを採用しています。アイコンは以下の点でMaterial 3と調和すべきです：

- **アイコンの線太さ**: Material Symbols の `weight: 500` 〜 `600` 程度の太さを想定
- **フィルスタイル**: `fill: 1`（塗りつぶし）に近い、面で構成されたアイコン
- **グレード**: `grade: 0`（標準的なコントラスト）
- **光学補正**: 完全な幾何学的中心ではなく、視覚的な中心を意識した調整

### 12.2 将来的な拡張性

- 将来的に **iOS / Android** への展開も視野に入れています。マルチプラットフォームで違和感のないデザインが望ましいです。
- アイコンのバリエーション（モノクロ版、逆色版、シンボルマークのみ版）をセットで作成できると理想的です。

## 13. まとめ：デザインのチェックリスト

デザイン提案時に、以下を満たしているか確認してください：

- [ ] **シンプル**: 遠くから見ても3秒以内に「飲食店の管理アプリ」と伝わるか
- [ ] **スケーラブル**: 16px で潰れず、1024px で美しく見えるか
- [ ] **カラー統一**: プライマリブルー（#2563EB）と白を基調としているか
- [ ] **Material親和性**: Flutter / Material 3 アプリのアイコンとして違和感がないか
- [ ] **日本語文脈**: 日本語UIに埋め込んでも違和感のない、国際的なデザインか
- [ ] **差別化**: POSアプリや在庫管理アプリの既存アイコンと明確に区別できるか
- [ ] **ターゲット共感**: 小規模飲食店オーナーが「このアプリなら使えそう」と感じる親しみやすさがあるか
